# Research Extracts

Эта папка хранит промежуточные результаты исследования Sony API.

Правило:
- сюда складываются исследовательские выводы;
- отсюда факты потом переносятся в `knowledge/sony/*.json`;
- не все extracts автоматически считаются подтверждённой истиной для runtime.

Текущие файлы:
- `ptp-handshake-session-analysis.md`
- `ptp-op-9202-9209-analysis.md`
- `ptp-device-properties-full-catalog-analysis.md`
