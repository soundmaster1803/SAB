# Model Footer Policy

Цель: в конце ответа коротко показывать, какой слой/модель участвовали.

## Минимальный формат
- `Источник: Ollama (локально)`
- `Источник: локальный tool layer`
- `Источник: Codex (облако)`
- `Источник: Claude (облако)`

## Расширенный формат
Если runtime реально даёт usage numbers, можно писать:
- `Источник: Codex (облако), usage: 134k/200k`

## Важное правило
Не придумывать usage numbers, если система их не дала.
Не писать псевдоточные токены для Ollama, если их нет в runtime.

## Для бытовых задач
Если задача выполнена локально, это надо явно отмечать:
- `Источник: Ollama + локальные инструменты`
